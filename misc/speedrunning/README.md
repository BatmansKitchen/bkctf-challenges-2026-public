# Speedrunning

**Flag:** `bkctf{m1nc3dr4ft_m4nhunt_0n3_hunt3r}`

## Solve

The flag is split into 4 parts hidden across a Minecraft world file.

1. **Part 1** - Reverse Bedrock patterns in the world to get your first checkpoint
2. **Part 2** - Use [Chunkbase](https://www.chunkbase.com/) to find a stronghold sitting on top of a cherry blossom biome
3. **Part 3** - Exit portal in the end
4. **Part 4** - The final fragment is at yalls's initial spawn point when loading the world.
